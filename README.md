# Kendi's Intro Page

Create a simple personal introduction landing page using only HTML and CSS.

The page should have one hero section.

Include:

Name: Kendi Christine

Subtitle: Frontend Developer

Description:

"I am a Chemical Engineering graduate building my skills in frontend development and creating simple, responsive and user-friendly web experiences."

Add a button labeled exactly:

"View My Projects"

Design it to look clean, modern and professional.

Use a light background with a professional accent color.

Center the hero content on the page.

Make it responsive on both desktop and mobile.

IMPORTANT:

Use plain HTML and CSS only.

Do not use React, TypeScript, Vite, or any framework.

I need a standalone index.html file that I can submit for an assignment.
